Your Nook bot (Python)

1. Install Python 3.8+ from python.org (tick "Add python to PATH").
2. Open .env in Notepad and paste your connect key after NOOK_KEY=.
3. Double-click start.bat. It installs what the bot needs, runs it, and starts it again if it stops.

Or by hand:  pip install https://YOUR-SITE/sdk/nook_bot-4.0.0-py3-none-any.whl  then  python mybot.py

The bot forgets everything when it stops unless you store it yourself (SQLite or MySQL). See the docs on the Nook Developer page.
Keep .env private: do not upload or share it.
